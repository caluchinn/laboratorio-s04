# Requisitos para instalar Git

Antes de instalar Git se recomienda contar con:

- Una computadora compatible.
  - macOS, Windows o Linux.
  - Permisos para instalar aplicaciones.
- Conexión a Internet para descargar el instalador.
- Al menos 200 MB de espacio libre.
- Una terminal disponible.
- Un editor de texto, como Visual Studio Code.
- Una cuenta de GitHub para publicar proyectos de forma remota.
