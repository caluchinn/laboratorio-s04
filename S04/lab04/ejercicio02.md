# Git

## Descripción

Git es un sistema de control de versiones distribuido que permite registrar cambios, recuperar versiones anteriores y colaborar en proyectos de software.

### Características principales

- Mantiene un historial completo de cambios.
- Permite trabajar con ramas independientes.
- Facilita la colaboración y la integración de aportes.
- Funciona localmente y puede conectarse con plataformas como GitHub.
